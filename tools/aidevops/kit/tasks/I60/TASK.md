# I60 — Выбор модели под задачу: pass@k и сравнение GLM, DeepSeek, Qwen

**Направление:** 14 inference. **После:** E28.

## Сценарий
Команда выбирает модель для кодинга по «процент решённых задач с одной попытки на 5 примерах» и по публичным лидербордам, не учитывая, что для критичных репозиториев годятся только локальные модели. Напиши несмещённый pass@k и выбор модели по профилю задачи: жёсткие ограничения отсекают кандидатов, среди оставшихся побеждает лучший pass@k, ничьи решают цена и TTFT.

## Контракт
```python
pass_at_k(n=10, c=3, k=1)  # 0.3
pass_at_k(n=10, c=3, k=5)  # 0.9166...
results = [
  {"model": "glm-4.6", "local": False, "ttft_p95": 1.4, "cost_per_1m": 2.2, "tasks": {"code": {"n": 20, "c": 15}}},
  {"model": "deepseek-v3.1", "local": False, "ttft_p95": 2.1, "cost_per_1m": 1.1, "tasks": {"code": {"n": 20, "c": 15}}},
  {"model": "qwen3-coder-30b", "local": True, "ttft_p95": 0.6, "cost_per_1m": 0.0, "tasks": {"code": {"n": 20, "c": 12}}},
]
select(results, {"task": "code", "k": 1, "critical": False, "max_ttft_p95": 3.0, "min_n": 20})
# {"model": "deepseek-v3.1", "ranking": [["deepseek-v3.1", 0.75], ["glm-4.6", 0.75], ["qwen3-coder-30b", 0.6]],
#  "rejected": {}}
```

- `pass_at_k(n, c, k)` — несмещённая оценка из статьи HumanEval: `1 − C(n−c, k) / C(n, k)`; если `n − c < k` — `1.0`. `ValueError`, если `k < 1`, `k > n`, `c < 0` или `c > n`.
- Отсев с причиной в `rejected`:
  - `critical: True` и модель не локальная — `cloud_for_critical`;
  - нет результатов по задаче — `no_results`;
  - попыток меньше `min_n` — `insufficient_samples` (на 5 задачах разница 60% и 80% — шум);
  - `ttft_p95 > max_ttft_p95` — `ttft`.
- `ranking` — `[model, pass@k]` по убыванию pass@k, при равенстве дешевле выше, затем быстрее.
- Никто не прошёл — `model: None`.

## Требования к результату
pass_at_k = 1 − C(n−c,k)/C(n,k), 1.0 при n−c<k, ValueError на некорректных n/c/k; select(): critical — только local, меньше min_n попыток — insufficient_samples, TTFT p95 выше порога — ttft, нет результатов по задаче — no_results; ранжирование по pass@k, затем цена, затем TTFT; нет кандидатов — model None.
