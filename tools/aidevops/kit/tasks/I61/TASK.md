# I61 — Малые модели: Whisper против GigaAM — WER и RTF на русской речи

**Направление:** 14 inference.

## Сценарий
Для транскрибации созвонов выбирают между Whisper (small, large-v3-turbo) и GigaAM. Текущая оценка сравнивает строки целиком, «Ёлка» и «елка,» считает ошибкой, а WER по корпусу усредняет по фразам, из-за чего короткие реплики весят как длинные. Напиши честную оценку: нормализация, WER по словам, корпусный WER, RTF и выбор модели с ограничением по скорости.

## Контракт
```python
normalize("Ёлка, ёжик — и т.д.!")          # "елка ежик и т д"
wer("мама мыла раму", "мама мыла рамы")    # 0.333...
corpus_wer([("да", "нет"), ("один два три четыре", "один два три четыре")])  # 0.2, а не 0.5
rtf(processing_seconds=12.0, audio_seconds=60.0)  # 0.2
choose({
  "whisper-small":          {"pairs": [...], "processing_seconds": 30, "audio_seconds": 600},
  "whisper-large-v3-turbo": {"pairs": [...], "processing_seconds": 240, "audio_seconds": 600},
  "gigaam-v2-ctc":          {"pairs": [...], "processing_seconds": 20, "audio_seconds": 600},
}, max_rtf=0.3)
# {"model": "gigaam-v2-ctc", "scores": {"whisper-small": {"wer": ..., "rtf": 0.05}, ...}}
```

- `normalize`: нижний регистр, `ё → е`, всё кроме букв и цифр (включая дефисы и тире) — пробел, пробелы схлопнуты.
- `wer(ref, hyp)` — расстояние Левенштейна по словам после нормализации, делённое на число слов эталона. Пустой эталон — `ValueError`: в eval-наборе его быть не должно.
- `corpus_wer(pairs)` — сумма правок по всем парам / сумма слов всех эталонов.
- `rtf` — real-time factor; `< 1` — быстрее реального времени.
- `choose`: модели с `rtf > max_rtf` в выбор не попадают, но остаются в `scores`; побеждает минимальный корпусный WER; никто не прошёл — `model: None`.

## Требования к результату
normalize: регистр, ё→е, пунктуация и дефисы в пробел, схлопывание пробелов; wer — расстояние Левенштейна по словам / число слов эталона, пустой эталон — ValueError; corpus_wer — сумма правок / сумма слов; rtf = время обработки / длительность аудио; choose — минимальный корпусный WER среди моделей с RTF не выше порога.
